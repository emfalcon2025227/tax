System Architecture & Role Guide

1. Blind Data Entry Protocol (index.html) Designed for data entry clerks on mobile and Android devices. It enforces strict write-only isolation: clerks can insert invoices with real-time 5% VAT calculations (inclusive/exclusive) and offline queuing, but cannot view historical balances, totals, or records.
2. Executive Admin Dashboard (admin.html) Designed for executives and tax consultants. Features full historical visibility, automatic FTA VAT Net calculation (Output Tax - Input Tax), 30-day moving average profit forecasting, single-page landscape Excel reports (.xlsx), PDF summary export (.pdf), and CSV batch importing.
3. Strict UAE Tax Compliance All transactions are validated against the 15-digit UAE Federal Tax Authority (FTA) Tax Registration Number rule. The smart supplier auto-fill strictly references the 19 registered enterprise suppliers.

The daily financial report can be scheduled via operating system cron (Linux/macOS) or Windows Task Scheduler:

0 8 * * * cd /path/to/project && python3 admin_backend.py --daily-report

Alternatively, trigger via HTTP Webhook: POST /api/cron/daily-report with header x-cron-secret.
